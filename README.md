# IR Project – Source Code Snippet Finder

## Project Objective

This project is a Flask-based web application that allows users to search and retrieve Python source code snippets. The application demonstrates basic Information Retrieval concepts by matching user search queries with stored code files and displaying relevant results dynamically.

---

## Tools and Technologies Used

- Python
- Flask
- HTML
- Git
- GitHub

## Installation Steps

1. Clone the repository:
   git clone https://github.com/rupithaofficial-hash/IR-Project-.git

2. Go to the project folder:
   cd IR-Project-

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

5. Open in browser:
   http://127.0.0.1:5000

---

## Application Features

- Search functionality for Python code snippets  
- Dynamic result display using Flask templates  
- Organized storage of source code files  
- Simple and user-friendly interface
